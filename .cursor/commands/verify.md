# 빠른 검증

방금 바꾼 것만 빠르게 본다. **끝났다고 말하기 전에는 `/ship` 을 돌려라 — 이건 중간 점검일 뿐이다.**

1. `git status` 와 `git diff --stat` 으로 내가 실제로 뭘 건드렸는지 확인한다.
2. 바꾼 파일이 속한 팀 규칙(`.cursor/rules/2*-team-*.mdc`)의 "이 팀만 검증하는 명령" 을 골라 돌린다.
3. 타입: `npx tsc -b`
4. 린트: `npx eslint <바꾼 파일들>`

## 규칙

- 실패를 숨기지 마라. 기존 테스트를 느슨하게 하거나 삭제해서 통과시키지 말고, **원인을 고친 뒤 다시 실행**해라.
- 테스트를 새로 썼으면 **음성 대조**를 해라 — 수정을 되돌렸을 때 그 테스트가 **실제로 실패하는지** 확인한다.
  되돌려도 통과하는 테스트는 장식이다.
- 결과를 그대로 보고해라. 실패했으면 실패했다고 출력과 함께 말한다.
