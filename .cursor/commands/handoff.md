# 인수인계 — 계정/세션을 바꾸기 전에

한도가 차서 다른 Claude 계정이나 새 세션으로 넘어가기 직전에 실행한다.
목표: **다음 세션이 이 대화를 안 읽고도 이어받을 수 있게** 만드는 것.

## 할 일

1. 현재 상태를 실제로 잰다:
   ```bash
   git status --short && git diff --stat && git log --oneline -5
   ```
2. `docs/handoff/` 에 `YYYY-MM-DD-<팀>-<한줄>.md` 로 아래를 쓴다. **추측 금지, 잰 것만.**

   - **무엇을 하려던 일인가** — 한 문단. 왜 이 작업을 하는지 포함.
   - **어디까지 됐나** — 파일별로 무엇을 바꿨고 **왜 그렇게 했는지**. 대안을 버린 이유도.
   - **게이트 상태** — 무엇을 돌렸고 무엇이 통과/실패했는지. **안 돌린 건 "안 돌렸음"이라고 적어라.**
   - **다음 한 걸음** — 이어받는 사람이 맨 처음 칠 명령 한 줄.
   - **건드리면 안 되는 것** — 이 작업 중에 발견한 함정.
   - **미해결 판단** — 내가 결정 못 하고 남긴 것.

3. 커밋하지 않은 변경이 있으면 **그대로 둔다.** `git stash`·`reset`·`checkout` 으로 치우지 마라(프로젝트 금지 사항).
4. 새로 알아낸 함정이 있으면 해당 팀 규칙(`.cursor/rules/2*-team-*.mdc`)에 **근거 파일:줄과 함께** 추가한다.

## 다음 세션이 할 일

```
docs/handoff/<그 파일> 을 읽고 이어서 해줘.
```
