# 팀 지도 다시 뜨기

팀 규칙 파일(`.cursor/rules/2*-team-*.mdc`)이 오래됐거나 `[보고 — 미검증]`/`전수 실측 중단` 표시가 붙어 있을 때 돌린다.

## 절차 — 추측 금지, 파일을 열어라

대상 팀을 하나 정하고(커뮤니티·내 매장·홈·GTO), 그 규칙 파일의 globs 에 걸리는 파일들을 실제로 읽어서 아래를 갱신한다.

1. **진입점** — 경로 · `wc -l` 줄 수 · 한 줄 역할. 존재하지 않는 경로는 삭제.
2. **lib / api** — 이 도메인 전용 파일.
3. **서버 표면** — `grep -o ".from('[^']*'"` 와 `grep -o ".rpc('[^']*'"` 로 실제 호출하는 테이블·RPC 를 수집.
4. **함정** — 이 도메인을 처음 만지는 사람이 **모르면 반드시 사고 내는 것**.
   각 항목에 **근거 `파일:줄`** 을 붙인다. 근거를 못 대는 항목은 쓰지 마라.
5. **열려 있는 것** — `docs/plans/BLOCKED.md` · `docs/plans/backlog.md` · 코드 내 TODO/FIXME grep.
6. **검증 명령** — 실제로 실행 가능한 명령줄.

## 검증 단계 (건너뛰지 마라)

갱신본을 쓴 다음, **적은 경로가 전부 실재하는지 다시 대조**하고 함정의 근거 줄을 열어 확인한다.
코드가 그렇게 되어 있지 않으면 그 항목을 **삭제**한다. 지운 건수를 맨 뒤에 `[검증에서 제거됨: N건]` 으로 적는다.

파일을 수정하거나 테스트를 실행하지 마라 — 읽기 전용 작업이다(대상 `.mdc` 파일 하나만 쓴다).
