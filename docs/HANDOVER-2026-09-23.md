다음 사람에게 **틀린 정보**가 된다(실제로 `App.tsx` 에 대해 LF/CRLF/mixed 세 판본의 기록이 공존한다).
그리고 실패 모드가 에러가 아니라 **0건 매칭**이라 치환 스크립트도 음성 대조도 "아무 일 없음"으로 초록을 낸다.

**지금 막혀 있나** — **강제 장치 없음.** `.githooks/pre-commit` 은 secretlint 전용이고 줄끝 검사 0줄,
`.claude/hooks/nuri-guard.mjs` 는 조언만 하고 `exit 0` 한다. 조언 문서만 있다: `.claude/skills/nuri-edit/SKILL.md`

> ### 🔧 작업 전 한 동작
> 편집 **전에** `git ls-files --eol <파일>` 로 `w/crlf`·`w/lf`·`w/mixed` 를 읽어라. 미추적 파일·BOM 은 바이트로:
> ```bash
> python -X utf8 -c "b=open(r'<파일>','rb').read();c=b.count(b'\r\n');print('CRLF',c,'loneLF',b.count(b'\n')-c,'BOM',b[:3]==b'\xef\xbb\xbf')"

> (줄끝이 뒤집히면 파일 전체가 diff 로 뜬다). 🔴 **`grep` 으로 줄끝을 세지 마라 — 오늘 거짓말했다.**

(a) `position` 특이도 싸움에서 배치를 부수거나 (b) 이웃 간격보다 크면 **남의 자리를 먹거나**
(c) `overflow-*` 조상이 있으면 **잘려서 무효**가 된다 — 셋 다 화면상으로는 멀쩡해 보인다.

**지금 막혀 있나** — 🔴 **막는 방향이 틀렸다.** 전역 스윕(`e2e/design-tokens.spec.ts:164`)이 있긴 한데
**크기만 재고** 홈 `/` 한 판에서만 돈다. 이웃 덮음·overflow 잘림·position 붕괴는 전부 이 계측에 **정상으로 나온다**
(세 사건 모두 여기서 안 잡혔다). 없는 것보다 위험하다 — **초록불이 안전의 증거로 읽히기 때문이다.**

> ### 🔧 작업 전 한 동작
> `.hit`/`tap-y-44`/`tap-up-24` 를 **붙이기 전에** 세 줄을 계산해라.
> 1. 한쪽 오버행 = `(44 − 실제 박스폭) / 2` → **이웃과의 gap 과 비교**
> 2. `el.closest('[class*="overflow-"]')` 가 잡히면 오버행은 잘린다 → **쓰지 마라**
> 3. `className` 에 `absolute|fixed|sticky` 가 있으면 **`.hit` 금지**
>
> 하나라도 걸리면 오버행 대신 **`h-[44px]` 실박스**로 가라.
> ⚠ 루트 폰트가 **17px** 이라 `h-11` = **46.75px** 이다. 44px 계약은 `h-[44px]` 로 써라.
> ⚠ Playwright click/tap 은 누름이 **0ms** 라 `:active`/`transform` 부류를 **절대 재현 못 한다** —
> CDP `Input.dispatchTouchEvent` 로 touchStart→(100ms+)→touchEnd 를 보내라(`e2e/pill-press.spec.ts`).

## 5. 절차 — 이 순서대로만 하면 위 대부분이 막힌다

### 시작할 때

```bash
git branch --show-current && git rev-parse --short HEAD && git status --short
md5sum public/sitemap.xml            # 값을 대화에 적어 둔다. 백업은 이때 한 번만.
gh run list --limit 1                # 도는 CI 가 있으면 푸시 금지
```

⚠ **보호 파일 백업은 세션 시작에 한 번, 복원은 마지막 게이트 뒤 한 번.**
중간에 다시 백업하면 오염본이 정상본을 덮는다(오늘 실제로 잃었다).

### 편집할 때

1. `git ls-files --eol <파일>` — 줄끝 먼저 (§B)
2. 공용 계산이면 정의 수부터 (§G)
3. 비동기 setter 면 `grep -nE '\.then\(set[A-Z]'` (§C)
4. 비동기 렌더면 `grep -n "return null"` (§I)
5. 히트영역이면 오버행 3줄 계산 (§J)

### 푸시 전

```bash
npm run gate          # 타입(tsc -b)·vitest·린트·빌드·번들예산·비밀스캔. sitemap 은 자동 백업·복원된다
npm run test:e2e      # ⚠ gate 에 E2E 는 없다. 그리고 이건 sitemap 을 덮는다
```

🔴 **`npx tsc --noEmit` 을 쓰지 마라 — 0개 파일을 검사하고 exit 0 을 준다**(오늘 실측). 진짜는 `tsc -b` 다.
🔴 **파이프에 물리지 마라** — `cmd | tail` 의 종료코드는 `tail` 의 것이라 앞이 죽어도 OK 가 찍힌다.

E2E 실패가 나면 **회귀로 단정하지 말고 격리 3회 반복**으로 갈라라:

```bash
npx playwright test e2e/<스펙>.spec.ts --workers=1     # 3회
```

> 오늘 실측: 전체 실행 **6 실패** → 격리 3회에서 `mobile-tab-transition` 14/14 · `post-nav` 10/10 ·
> `mystore-transition-cls` 6/6 **전부 통과**. CI 도 초록이었다. 이 머신은 전체 병렬에서 flake 를 만든다.

### 푸시하고 나서

```bash
gh run list --limit 1                                                   # completed 까지 대기
curl -s "https://nuriholdem.com/?cb=$(date +%s)" | grep -oE 'assets/index-[A-Za-z0-9_-]+\.js'
```

마지막으로 **지운 것이 정말 지워졌고, 옆의 비슷한 것은 살아 있는지** 번들에서 확인해라(음성 + **양성 대조**).
