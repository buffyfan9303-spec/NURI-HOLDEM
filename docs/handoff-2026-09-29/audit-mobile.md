1. **운영 데이터 불일치**: 홈·일정·라이브에 보이는 대회 전부의 `pub_name` 이 "누리 테스트 홀덤펍", `address` 가 "서울 강남구 테헤란로 1" 이다. 그런데 `venue_id` 는 `f35b42d1…`(= **로티아레나**, 경기북부 남양주)이다. 그래서 카드의 "누리 테스트 홀덤펍" 을 누르면 로티아레나 매장 페이지가 열린다. 같은 이름의 테스트 매장(`dddd0000…`, 서울)이 공개 매장 목록에 따로 있다. 상세 설명에 "[더미 2026-09-26 레이아웃 확인용]" 이 있어 더미 일정으로 보인다
2. 더미 일정의 `buy_in.gameType` 에 `gtd`·`entry` 가 들어 있어서 상세 '참가비' 줄에 **"300,000 · gtd"** 처럼 영어 소문자 코드값이 그대로 보인다(`ScheduleDetailModal.tsx:1543` 은 자유 입력값을 그대로 붙인다)
3. 공개 활동 순위 3위에 **"E2E검증업주" 16점** 이 보인다(커뮤니티 → 순위). 테스트 계정이 운영 공개 화면에 나온다
4. 게시판 최근 글에 "ㅇ"·"ㅎㅇ"·"d"·"댜마머ㅓ재"(작성자 나누리) 같은 시험 글이 공개돼 있다
5. `server_now` RPC 가 운영에 없다(위 D9) — 클락 서버 시각 보정이 켜지지 않았다
