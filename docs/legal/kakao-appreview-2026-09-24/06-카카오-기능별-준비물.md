## 5. 오너가 추가로 고려할 것

1. **카카오톡 채널을 먼저 만든다.** 알림톡의 필수 조건이고, 카카오 로그인 동의 화면에 '대표 채널'로도 쓸 수 있다(선택).
   비즈니스 채널 심사에서도 업종을 보므로, 앱 심사와 **같은 사행성 판단이 채널 쪽에서 다시 나올 수 있다**(확인 필요).
2. **개인정보처리방침 개정 항목** (알림톡·카카오 로그인 시작 **전**, 앱 재심사 게시 **전** 권장):
   - (a) 수집 항목에 '카카오 로그인 시: 닉네임·프로필 사진·카카오계정 이메일(필수/선택 구분)'과 목적 '회원가입·식별'
   - (b) 휴대전화번호 이용 목적에 '매장이용권 사용 안내(카카오 알림톡)'
   - (c) 처리 위탁에 알림톡 딜러사(계약 후 이름)와 카카오
   - (d) 출석 위치 확인: 휴대폰 위치를 출석 판정에만 쓰고 즉시 파기한다는 문장 + 위치기반서비스 약관 연결
   - 개정 파일: `src/pages/legal/PrivacyPolicy.tsx`, `src/components/features/LegalDocsModal.tsx`, `public/legal/privacy.html`, 버전 `src/lib/legalVersion.ts`
     (계약 테스트 `src/components/features/legalConsentHistory.contract.test.ts` 도 같이 본다). 중요한 변경은 30일 전 고지(현 방침의 고지 의무 조항).
3. **위치기반서비스 약관 개정 + 신고 판단** — `checkin_geo_enabled` 를 켜기 **전에**. 켜기 전까지는 좌표가 서버로 가지 않는다.
4. **카카오 JS 키 = 공유 자동 활성화.** 지도만 켜려 해도 카카오톡 공유 버튼이 같이 살아난다(`src/lib/kakao.ts`). 공유도 쓸지 정하고, 쓰면 소명서 6-② 의 [선택] 줄을 남긴다.
5. **카카오 로그인 사용자도 같은 19세 게이트**를 지나야 한다. 로그인만으로 글쓰기·예약·이벤트가 열리지 않는지 복원 후 확인(NOT_RUN).
   예전 카카오 로그인은 성공 이력이 0건이었다 — 원인을 모른 채 복원하면 같은 실패가 날 수 있다(확인 필요).
6. **비용 요약**: 로그인·비즈 앱·동의항목 심사 = 무료. 카카오맵·공유 = 무료 한도 안 무료. 알림톡 = **딜러사 견적**(건당 과금). 위치기반서비스 신고 수수료 = 확인 필요.
7. **§28 문구**: 알림톡·소명서에 '환전·현금·수익' 계열 단어를 쓰지 않는다. '이용권·참가비·상금'으로 통일.
