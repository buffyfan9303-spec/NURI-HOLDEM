## 1. 재심사가 또 반려되면 — 카카오 기능 범위를 줄이는 선택지

### 선택지 A. 카카오 개발자 앱 없이 운영 (현상 유지)

- 내용: 심사를 포기하고 카카오 API 를 쓰지 않는다. 공유는 기기 공유창(`navigator.share`)·링크 복사, 지도는 네이버 지도.
- **코드 영향: 없음.** 지금 라이브가 이미 이 상태다(라이브 번들의 `kakaoConfigured()` 가 false).
  - 공유 폴백: `src/lib/kakao.ts:3`(실패 시 false → 호출부 폴백), `CustomerDashboardPage.tsx` 의 `copy()`/`navigator.share`
  - 지도: `src/components/features/VenuePage.tsx:1682-1689`(네이버 우선 → 카카오 → '위치 정보 준비 중')
  - 오픈채팅 링크·카카오맵 검색 링크는 개발자 앱이 필요 없어 그대로 동작한다.
- 잃는 것: 카카오톡 리치 카드 공유(이미지 카드), 카카오맵 지도 표시.
- 로그인: Google 로그인 + 이메일 가입 유지(`src/api/auth.ts:810` "소셜 로그인은 Google 하나").

### 선택지 B. 카카오톡 공유만 (지도·로그인 제외)

- 내용: 심사 신청 범위를 '카카오톡 공유'로 좁혀 다시 신청. 지도는 네이버 유지.
- 코드 영향:
  - 키가 하나(`VITE_KAKAO_MAP_KEY`)로 공유·지도에 같이 쓰인다. 공유만 켜려면 키를 넣는 순간 카카오 지도 분기도 살아난다 —
    단, 네이버 키가 있으면 네이버가 이긴다(`VenuePage.tsx:1682-1689`). 네이버 키가 라이브에 있는지 먼저 확인할 것(NOT_RUN).
  - 키 분리가 필요하면 `src/lib/kakao.ts:4` 와 `src/components/features/VenuePage.tsx:1607` 두 곳의 환경변수 이름을 나눈다.
  - CSP 는 이미 `kakao.com`·`kakaocdn.net` 허용(`vercel.json`) — 변경 불필요.
- 위험: 서비스 자체가 제한 카테고리로 판정되면 범위를 줄여도 같은 반려가 날 수 있다(반려 사유가 '기능'이 아니라 '서비스'이기 때문).

### 선택지 C. 카카오 로그인만

- 내용: 가입 편의를 위해 카카오 로그인만 신청.
- 코드 영향: 2026-09-10 삭제한 `loginWithKakao` 를 git 이력에서 되살려야 한다(`src/api/auth.ts:809-810` 안내).
  로그인 버튼(`src/components/features/AuthModal.tsx`), OAuth 오류 안내(`src/App.tsx:2788` 부근), Supabase Auth 의 kakao 제공자 설정, 테스트(`src/api/auth.social.test.ts`)까지 같이 본다.
- 위험: 동의항목 심사가 붙는다. 카카오는 **카카오 로그인이 주는 출생연도로는 성인 확인이 안 된다**고 본다(https://devtalk.kakao.com/t/4-4/150561)
  → 우리는 어차피 PortOne 본인인증으로 19세를 막으므로 동의항목에 생년을 요청할 필요가 없다. 제공자 성공 이력이 0건이었다는 점도 참고.

### 선택지 D. 공유 전용 앱을 별도로 등록

- 내용: 같은 사업자로 다른 카카오 앱을 만들어 공유만 쓴다.
- **추천하지 않음.** 운영정책의 금지 행위 목록에 "동일한 서비스를 위해 여러 앱을 만드는 행위"가 있다(2026-09-24 원문 요약으로 확인, 조 번호는 미확인).
  반려를 피하려는 우회로 보일 수 있다.

### 선택지 E. 문의 답변을 받아 해당 기능만 조정

- 내용: 소명서 끝에 "어떤 기능 때문인지 알려 주면 조정하겠다"고 적어 두었다. 답변이 특정 기능(이벤트·상금 표시·순위 등)을 지목하면 그 기능만 고친다.
- 코드 영향: 지목된 기능에 따라 다르다. 미리 알려진 후보:
  - 이벤트: `src/components/features/EventPage.tsx`, `src/api/events.ts`, 홈 배너 `src/components/features/HomeTab.tsx`
  - 상금·GTD 표시: 포스터 상세·클락 표·변환 로직(유권해석 문서 질문 ②의 "최소 5곳")
  - 순위·시즌 점수: `src/api/rankings.ts`, `src/components/features/SeasonPanel.tsx`
- ⚠ 기능 삭제는 CLAUDE.md "기능·데이터 보존" 규칙에 걸린다. 숨김·문구 변경을 먼저 검토하고, 삭제는 오너 결정으로만.

## 2. 한 줄 정리

재심사가 막혀도 **지금 라이브는 카카오 없이 이미 돌고 있다(선택지 A, 코드 영향 0)**. 급하게 무언가를 지울 이유는 없다.
재심사 성공 확률을 올리는 가장 싼 방법은 코드가 아니라 **이벤트를 숨기거나 끝난 뒤에 게시하는 것**이다.
