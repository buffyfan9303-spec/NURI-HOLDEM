## 작성에 쓴 도구 (재현용)

- 코드 사실: `grep`/`sed` 로 메인 체크아웃 `src`·`supabase/functions`·`public` 확인.
- 라이브 DB(읽기 전용 조회만): Supabase MCP `execute_sql` — `event_campaigns`, `app_settings`, `auth.identities`, `store_vouchers`, `voucher_transfers` 행 수.
- 라이브 번들: `curl` 로 `https://nuriholdem.com/assets/*.js` 108개 청크를 받아 `kakao_js_sdk` 문자열 부재와 `kakaoConfigured` 컴파일 결과 확인.
- 캡처: 메인 체크아웃의 `node_modules/playwright`, 스크립트는 세션 scratchpad(`cap.cjs`).
- 정책·사례: WebFetch(카카오 운영정책 원문, 데브톡 글), WebSearch. firecrawl 스크레이프는 파라미터 검증 오류로 실패해 WebFetch 로 대체했다.
