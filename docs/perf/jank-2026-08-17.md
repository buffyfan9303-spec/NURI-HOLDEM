## 수정 (커밋 1개, 24건 편집)

1. **부팅 배칭** — schedules/venues/notices 3건, 지연 로드 5건(posts·comments·listings·ratings·liveCount)을 `Promise.allSettled` 단일 콜백으로(8렌더→2렌더)
2. **참조 유지 가드** — 재조회 결과가 내용 동일이면 이전 배열 참조 반환(`sameJson`) → 실시간 디바운스·창 복귀 시 재렌더 생략
3. **deps 축소** — 알림·팔로우 이펙트 `[user]`→`[user?.id]`
4. **memo 복구** — `handleOpenWrite`/`handleMarketCreate` ref 패턴(커뮤니티·장터 memo 파손 해소), AppHeader·TabBar·MobileTabBar·PastTournaments·BrowseSideRail memo 래핑 + 호출부 인라인 화살표/객체 안정화
5. **예약자 수 이중 조회 제거** — id 집합 문자열 키 가드
6. **페인트 3건** — `body::before` 고정 레이어(스크롤 재페인트 0) · tier-glow 정적화 · ScheduleCard `transition-[transform,border-color]` + 글로우 blur 26→12px
7. **광고 유예** — AdSense 로드를 (load+첫 데이터 응답) 신호 후 **+3.5s** 유예 → 첫 상호작용 구간과 분리
