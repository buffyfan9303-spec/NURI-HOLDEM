## 결론

소스를 전수 확인해 실제 기능만으로 스토어 등록정보 3종(앱 이름 22자 / 짧은 설명 46자 / 전체 설명 1,782자)을 완성했다. 탭 구조는 홈·일정 탐색·라이브·커뮤니티·GTO·캘린더(또는 내 매장)·관리자이며(src/App.tsx:1657-1667), GTO 탭 도구는 22종·매장 운영 도구 5종으로 실제 배열과 일치시켰다(ToolsPanel.tsx TOOLS 27개 중 STORE_TOOL_KEYS 5개 분리). 오리엔테이션의 "PortOne 결제가 붙어 있다"는 소스와 다르다 — PortOne은 본인인증(requestIdentityVerification) 전용이고 이용권 유상 충전 경로는 §12-A-2로 폐쇄되어 있어, 카피에 결제·인앱구매를 쓰면 허위 기재가 된다. '환전·현금·수익'은 전체 원고에서 0회이며(법적 문서명 '불법 환전…서약'도 '사행성 행위 금지 서약'으로 우회), 도박 앱이 아님은 별도 소제목과 첫 문단 두 곳에서 드러냈다.



## 근거 (위험도 · 출처)

- **[blocker]** PortOne은 결제가 아니라 본인인증 전용이다. 이용권 유상 충전은 §12-A-2로 서버·화면 모두 폐쇄됐고, 관리자 화면도 '반려만 가능'이다. 따라서 스토어 카피·데이터보안 양식에 '결제·인앱구매·유료 아이템'을 기재하면 안 된다.
  · 출처: `src/components/features/IdentityVerificationButton.tsx:45 (PortOne.requestIdentityVerification) · src/api/identity.ts:1 · src/components/features/AdminTab.tsx:163,167 · src/components/features/VoucherManageModal.tsx:56,440`

- **[high]** 앱에 AdSense Auto Ads 로더가 실려 있다(수동 <ins> 슬롯 0개). Play Console 스토어 등록정보에서 '광고 포함'을 체크해야 한다.
  · 출처: `index.html:21-23 · src/main.tsx:71-74 · PLAYSTORE.md '광고 포함 여부(AdSense 사용)'`

- **[high]** 만 19세 미만 이용 불가가 서비스 규약에 명시돼 있다. 콘텐츠 등급 설문에서 '실제 금전이 걸린 도박 없음 + 성인 대상'으로 일관되게 답해야 카피와 어긋나지 않는다.
  · 출처: `public/legal/anti-gambling.html '본 서비스는 만 19세 미만 청소년은 이용할 수 없습니다'`

- **[medium]** GTO 탭에 노출되는 학습 도구는 22종이다(TOOLS 배열 27개 − STORE_TOOL_KEYS 5개). 파일 주석의 '26개'는 오기이므로 카피에 26을 쓰면 안 된다.
  · 출처: `src/components/features/ToolsPanel.tsx:46-84 (TOOLS 27개) · :92 (STORE_TOOL_KEYS = chip, sim, blindgen, payout, endtime)`

- **[medium]** Play 앱 이름(한글 '누리홀덤 …')과 manifest의 name 'NURI HOLDEM'이 다르다. TWA 런처 아이콘 아래 이름은 .aab 빌드 시점 값이라, 스토어 제목만 바꾸면 설치 후 홈화면 이름과 갈린다.
  · 출처: `public/manifest.webmanifest ("name": "NURI HOLDEM", "short_name": "NURI") · PLAYSTORE.md 2·4번 절`

- **[low]** 카피에 적은 기능은 전부 소스에 존재한다 — 길찾기(카카오맵 링크), 구글/아이폰 캘린더 저장, 시작 전 푸시 알림, QR 체크인 인증자만 후기 작성, 장부 엑셀 내보내기, 클락 TV 송출·휴대폰 리모컨, AI 후기 답글 초안, 직원 근무표·급여.
  · 출처: `ScheduleDetailModal.tsx:303,628(map.kakao link)·:22(googleCalendarUrl,icsDataUrl)·:23(enablePush) · src/api/reviews.ts:1(체크인 인증자만 RLS),:37(aiDraftReviewReply) · NuriPosLedger.tsx:6,1250(엑셀) · clock/ClockDisplay.tsx:2-3 · clock/ClockRemote.tsx:8 · StaffSchedule.tsx, StaffPayroll.tsx`

- **[low]** 전체 설명 마지막 줄의 키워드 나열 문장은 Play 스팸 정책상 '무관한 키워드 반복'으로 읽힐 여지가 아주 낮게 존재한다(모두 앱과 직접 관련된 단어이고 문장 형태라 통상 문제되지 않음). 불안하면 그 한 줄만 삭제해도 본문 손실이 없다.
  · 출처: `Google Play 스팸·최소 기능 정책(등록정보 키워드 스팸) — 불확실: 정책 원문 URL 미확인`


## 조치

- [🧑 오너만 가능] 완성 원고 3종(앱 이름 / 짧은 설명 / 전체 설명)을 그대로 붙여넣는다. 글자수는 22·46·1,782자로 각각 30·80·4,000자 한도 안이다.
  · 위치: Play Console → 앱 → 성장 → 스토어 등록정보 → 기본 스토어 등록정보

- [🧑 오너만 가능] '광고 포함' 체크. AdSense Auto Ads 로더가 실려 있어 미체크 시 정책 위반이다.
  · 위치: Play Console → 앱 콘텐츠 → 광고

- [🧑 오너만 가능] 데이터 보안 양식을 실제 수집 항목으로 채운다: 이메일·닉네임·프로필 이미지·웹푸시 토큰·본인인증 결과(CI 해시)·위치(길찾기 실행 시 일시 사용, 저장 안 함). 결제·금융정보는 수집하지 않는다고 답한다(PortOne은 본인인증 전용).
  · 위치: Play Console → 앱 콘텐츠 → 데이터 보안

- [🧑 오너만 가능] 콘텐츠 등급 설문에서 '실제 금전이 걸린 도박·시뮬레이션 도박 게임 없음'으로 답하고, 성인(19세 이상) 대상임을 카피와 일치시킨다.
  · 위치: Play Console → 앱 콘텐츠 → 콘텐츠 등급

- [🧑 오너만 가능] 개인정보처리방침 URL로 https://nuriholdem.com/legal/privacy.html 을 입력한다(이미 라이브).
  · 위치: Play Console → 앱 콘텐츠 → 개인정보처리방침

- [🤖 코드/문서 작업] TWA 런처 이름을 스토어 제목과 맞출지 결정한다. manifest name 은 'NURI HOLDEM'이라 홈화면 아이콘 아래는 영문으로 뜬다. 한글로 통일하려면 manifest 의 name/short_name 을 바꾸고 .aab 를 재빌드해야 한다(웹 배포만으로는 안 바뀜).
  · 위치: public/manifest.webmanifest 3~4행 + PLAYSTORE.md 2·5번 절

- [🤖 코드/문서 작업] manifest 의 description('전국 홀덤 대회 일정 · 커뮤니티 · GTO · 매장관리')과 index.html 메타 설명을 새 짧은 설명과 같은 톤으로 맞춘다(선택 — 스토어 심사와 무관하지만 설치 배너·검색 스니펫에 노출된다).

■ 도박 앱이 아닙니다
누리홀덤에는 베팅 기능이 없습니다. 게임은 등록된 오프라인 매장에서 진행되고, 앱은 일정 안내·기록·학습·매장 운영만 다룹니다. 참가비를 받고 상금을 지급하는 일은 각 매장이 직접 하며, 회사는 그 과정의 당사자가 아닙니다. 앱에 적힌 참가비와 GTD는 매장이 등록한 상품 가격 정보입니다.
활동 점수와 매장 이용권은 활동 기록을 나타내는 표시값입니다. 금전적 가치가 없고, 사고팔거나 다른 사람에게 넘길 수 없습니다.
