위 표는 기본값이지 고정값이 아니다. 같은 역할이라도 작업에 따라 생성 모델을 바꿔 부른다.

바꾸려면 체크포인트를 받고 **다음 위임에서 새로 생성**한다.

## 3. `claude-fable-5-1` — 희소 자원이다. 리드만 부른다

Fable 은 총 한도를 공유하며 별도 무료 잔량이 아니다. 잔여량이 적다는 오너 지시가 이전 기본 배정보다 우선한다.
**개편·인벤토리·역할 생성·해시 비교·등록 시험에는 Fable 0회가 기본이다.**

아래 셋 중 **하나라도 해당할 때만** 부른다. (독립 검증 자체는 늘 하고, Fable 만 조건부다.)

1. 이용권·장부·권한·GTO 의 중요한 결론에 **독립 기준이 충돌**하고, 잘못 채택하면 데이터·권한 사고가 난다.
2. 같은 결함이 **재발**했고 Opus 의 재현·가설·대조 실험 뒤에도 **설명되지 않는 관찰**이 남았다.
3. 중요한 시각 판정을 실제 화면과 측정으로도 **두 독립 검토자가 다르게** 판정했다.

보낼 때는 **한 번에 한 쟁점**만: 요구 키 · 해시/diff · 재현 조건 · 관련 원문 · 관측값 · 반증한 가설 ·
판정할 불변식 · 아직 없는 증거. 같은 자료를 바꾸지 않고 재질문하지 않는다.
Fable 응답은 실행 테스트·서버 검증·영상 증거를 **대신하지 못한다**.

🔴 **자료가 없는 문제는 모델을 올려도 해결되지 않는다.** S26 실기기가 없거나 다인 Nash 의 독립 오라클이
없으면 `NOT_RUN`/`BLOCKED` 를 유지하고 근거를 모은다.

한도 부족이나 추가 크레딧 화면이 나오면 **유료 경로를 끝내고** 체크포인트를 Opus 5 로 넘긴다.
Opus 도 못 쓰면 상태를 보고하고 결과를 저장한다. **자동 계정 전환·크레딧 구매·반복 호출은 하지 않는다.**
`ANTHROPIC_API_KEY` 는 값을 출력하지 말고 존재 여부만 확인한다(2026-09-21 실측: 미설정).

## 4. 팀 실행

- 기본 크기는 **리드 + 담당자 + 독립 검토자**, 필요할 때만 탐색/소비자 1명 — 처음에는 **4명 이하**.
- 끝난 팀원은 체크포인트와 기억을 제출하고 종료한다. 남아 있는 팀원이 있는데 런타임 디렉터리를 지우지 않는다.
- **장문 설계서를 팀원 프롬프트에 복사하지 않는다.** 읽을 파일 경로를 주고 직접 읽게 한다.
- 자동 memory/skills 주입을 전제하지 말고 **절대 경로를 생성 프롬프트에 명시**한다.
- 같은 checkout 의 편집은 **직렬**, 읽기 전용 조사만 병렬. 파일별 편집자는 정확히 한 명.
- 정의를 고쳐도 **이미 실행 중인 팀원의 프롬프트·모델은 바뀌지 않는다.** 새로 생성해야 반영된다.

### 위임 프롬프트 뼈대

```text

요청 모델은 <모델 ID>, 이유는 <위험/작업 내용>다. 실제 모델은 리드가 실행 기록으로 확인한다.
먼저 <절대경로의 자기 MEMORY.md>, docs/TEAM-KNOWLEDGE.md 의 <관련 교훈 ID>,

소비자는 <역할>, 독립 검증자는 <역할>이다. 내 가설을 전제하지 말고 반증해라.

새 교훈은 증거와 원문 링크를 붙여 자기 기억에 남기고, 정책 변경은 리드에게 제안한다.
```

## 5. 모델은 **관찰**하고, 주장하지 않는다

- 요청 모델과 실제 resolved 모델은 별개다. **팀원이 스스로 말한 모델명은 증거가 아니다.**
- 실행 기록·상태 표시의 모델 필드로 확인한다.
- 재정의(`CLAUDE_CODE_SUBAGENT_MODEL` 등)가 있으면 그것이 이긴다. 2026-09-21 실측: **전부 미설정**.
- 공급자 대체·사용 불가·추가 결제 요구는 **숨기거나 자동 동의하지 않는다.** 오너에게 알리고 Opus 5 로 계속한다.
- 지원되지 않는 모델 ID·effort 를 만들어 내지 않는다. 확인된 ID:
  `claude-opus-5` · `claude-sonnet-5` · `claude-fable-5-1` · `haiku`(Haiku 4.5).

## 6. 역할이 하지 않는 것

- 하위 역할은 자기 정의·`.claude/skills/**`·`.claude/hooks/**`·`CLAUDE.md`·`AGENTS.md`·`.claude/settings.json` 을
  **자율적으로 수정하지 않는다.** 개선점은 근거와 함께 리드에게 제안하고 판단은 리드가 한다.
- 검토자(`design-reviewer`·`root-cause-debugger`·`critical-reviewer`·`verifier`)는 **제품 소스 읽기 전용**이다.
  자기 기억에만 쓴다. ⚠ `memory` 가 켜지면 Read/Write/Edit 도구가 붙을 수 있으므로
  "tools 에 Edit 가 없으니 못 고친다"를 보장으로 쓰지 말고 **실행 전후 diff 로 확인**한다.
- DB/RLS/RPC 마이그레이션의 작성과 적용 판단은 **리드만** 조정하고, 쓰기 전에 `.claude/skills/nuri-migration/SKILL.md` 를 읽는다.
- 필요 없는 플러그인·LSP·커넥터를 설치하지 않는다. **설치·등록·연결·실사용은 따로 보고한다.**
